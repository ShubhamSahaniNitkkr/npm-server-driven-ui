Configuration Guide

Everything is JSON. Each UI element has a type and optional props.

Basic page structure

{
  "type": "page",
  "title": "User Management",
  "children": [
    { "type": "input", "name": "search", "label": "Search" },
    { "type": "button", "text": "Save", "variant": "primary" }
  ]
}
import { ConfigProvider } from 'antd';
import { SDUIRenderer } from '@shubhamsunnynitkkr/server-driven-ui';
import { createAntdRegistry } from '@shubhamsunnynitkkr/server-driven-ui-antd';

<ConfigProvider>
  <SDUIRenderer
    schema={schema}
    registry={createAntdRegistry()}
    context={{ users: myUsers }}
    onSubmit={(data) => console.log(data)}
  />
</ConfigProvider>

SDUIRenderer props

PropRequiredWhat it does
schemaYesJSON describing the page UI
registryYesComponent map — use createAntdRegistry()
contextNoData for templates like {{users}}
onSubmitNoCalled when a submit action fires
onNavigateNoCalled on navigate actions
themeNo"light", "dark", or custom theme object
