Build UIs from JSON

How to Configure npm package

What the npm package does

Core engine

@shubhamsunnynitkkr/server-driven-ui reads your JSON schema and renders a React component tree.

UI components

@shubhamsunnynitkkr/server-driven-ui-antd provides 30+ ready-made components: inputs, tables, buttons, modals.

Charts (optional)

@shubhamsunnynitkkr/server-driven-ui-charts adds line, bar, pie, and area charts.

How it works

Backend API
sends JSON
→
SDUIRenderer

Install

npm install @shubhamsunnynitkkr/server-driven-ui @shubhamsunnynitkkr/server-driven-ui-antd react react-dom antd
import { SDUIRenderer } from '@shubhamsunnynitkkr/server-driven-ui';
import { createAntdRegistry } from '@shubhamsunnynitkkr/server-driven-ui-antd';

<SDUIRenderer schema={schemaFromApi} registry={createAntdRegistry()} />
