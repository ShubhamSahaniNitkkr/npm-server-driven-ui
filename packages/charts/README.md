# @shubhamsunnynitkkr/server-driven-ui-charts

Chart components for [@shubhamsunnynitkkr/server-driven-ui](../core).

```bash
npm install @shubhamsunnynitkkr/server-driven-ui-charts @shubhamsunnynitkkr/server-driven-ui recharts
```

```tsx
import { createAntdRegistry } from '@shubhamsunnynitkkr/server-driven-ui-antd';
import { withCharts } from '@shubhamsunnynitkkr/server-driven-ui-charts';

const registry = withCharts(createAntdRegistry());
```
